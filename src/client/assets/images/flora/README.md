# 🌿 Wild Flora Asset Directory

This directory is designated for high-resolution, modular PNG sprites representing wild flora in TastyTails.net.

### Registered Flora Asset Keys:
1. `flora_tall_grass.png` - Wild Tall Grass
2. `flora_clover.png` - White Clover Patch
3. `flora_dandelion.png` - Yellow Dandelion
4. `flora_flower_1.png` - Red Poppy
5. `flora_flower_2.png` - Blue Starflower
6. `flora_flower_3.png` - Yellow Marigold
7. `flora_berry_bush.png` - Sweet Berry Bush

Default texture files are synchronized to `/assets/tilemaps/` for client asset streaming.
